# Electrochemistry data automation

Python/R workflows for three electrochemical assays used in the wearables
project. Each project follows the same general sequence:

```text
instrument export -> convert (optional) -> tidy -> analyse -> plot
```

Run all commands from the repository root so the relative `Data/` paths
resolve consistently.

## Projects

### 1. Ion-transport charge (`ion_transport_charge/`)

Integrates chronoamperometry current traces to cumulative charge, then tests
candidate time windows to find the best linear calibration between charge and
concentration.

- Input: `.txt`/`.csv` files with `Time/sec` and `Current/A`.
- Filename pattern: `0.1mM KCl 1.0.csv` (`concentration`, `units`, optional
  analyte name, `sample ID`).
- Outputs: `Data/<experiment>/<experiment>_Tidy/` and `_Final/`, including
  `intercept_optimisation.csv`.
- Plot: `plotting.R` produces a charge-concentration calibration curve.

```bash
python electrochemistry/ion_transport_charge/main.py demo_ion
Rscript electrochemistry/ion_transport_charge/plotting.R
```

### 2. Open-circuit potential (`open_circuit_potential/`)

Parses stepped OCP recordings, checks the step sequence for missing or
duplicated concentrations, computes mean OCP over a trailing window, and fits
Nernst slopes (optionally separated into ascending/descending directions).

- Input: files with `Time/sec` and `Potential/V` (or `Voltage/V`).
- Filename pattern: `0.1mM KCl 1.0_2.csv` (`concentration`, `units`, optional
  analyte name, `sample ID`, `step`). A space before the step is also accepted.
- Outputs: `ocp_final.csv`, `ocp_tidy_long.csv`, and `slopes.csv`.
- Plot: `plotting.R` produces OCP-vs-time, calibration, RSD, and aggregate
  calibration figures.

```bash
python electrochemistry/open_circuit_potential/main.py demo_ocp
Rscript electrochemistry/open_circuit_potential/plotting.R
```

For four-channel continuous OCP data, set `channels > 1` in the `main()`
arguments or call `process_data.process_4channel_ocp` directly. That path
detects segment boundaries from potential drops.

### 3. Randles–Ševčík (`randles_sevcik/`)

Extracts peak currents from cyclic voltammograms, fits peak current against
the square root of scan rate, and estimates electrode area from the
Randles–Ševčík slope.

- Input: `.txt` exports with `Potential/V` and `Current/A`.
- Filename pattern: `10 mVs Bare_1.txt` (`scan rate` in mV/s, `electrode ID`).
- Outputs per batch: `summary.csv` and `slopes.csv`, plus
  `Ip_vs_ScanRate.png`.
- Plots: `plotting.R` and `CV.R` produce scan-rate and area figures.

```bash
python electrochemistry/randles_sevcik/handle_data.py \
  Data/randles/raw/Bare_Electrode Data/randles/tidy/Bare_Electrode_Tidy
python electrochemistry/randles_sevcik/process_data.py \
  Data/randles/tidy/Bare_Electrode_Tidy
Rscript electrochemistry/randles_sevcik/plotting.R
Rscript electrochemistry/randles_sevcik/CV.R
```

`plotting.R` expects the batch folder names `Bare_Electrode_Tidy` and
`AuND_Tidy`; edit `batch_keep` at the top of the script if your batch names
differ.

## PalmSens `.pssession` files

The `convert.py` modules convert PalmSens `.pssession` files to CSV. This code
is intentionally left as-is: it is tailored to the specific instrument and
file format used in the lab, and the vendor documentation for automated
parsing is limited. It requires the optional dependencies:

```bash
pip install -r requirements-palmsens.txt
```

If no `*_Psess` folder is present, the pipelines use direct `.txt`/`.csv`
exports and do not need `PyPalmSens`.

## Python dependencies

```bash
pip install -r requirements.txt
```

The optional PalmSens converter is described below.

## R dependencies

The plotting scripts use:

```r
install.packages(c("tidyverse", "ggsci", "scales"))
```

Generated figures are written under the corresponding `Data/` experiment
folder, not into the source tree.

## Data layout

See [`../docs/data-layout.md`](../docs/data-layout.md) for the full directory
convention. In short:

```text
Data/<experiment>/
├── <experiment>_Psess/   # optional
├── <experiment>_Raw/
├── <experiment>_Tidy/
└── <experiment>_Final/
```

No raw laboratory data is included in this repository. The synthetic demo
data is generated by `examples/generate_synthetic_data.py`.

## Notes and assumptions

- Currents from PalmSens are stored in µA in the raw export and converted to
  amperes by the converter.
- OCP slopes are reported in V/decade; the plotting script converts them to
  mV/decade.
- Randles–Ševčík assumes a diffusion-controlled, reversible process with the
  constants in `process_data.CONFIG`. Update `n`, `dr`, and `conc` for a new
  system.
- The ion-transport intercept search currently scans 40–120 s. Change
  `time_steps` in `process_data.py` if your acquisition window differs.
